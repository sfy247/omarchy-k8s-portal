# DNS and TLS

Back to [Home](index.md). The request path is in [03 Kubernetes Networking and Gateway](03%20Kubernetes%20Networking%20and%20Gateway.md).

## Hostname scheme

| Pattern | Resolves to | Example |
|---|---|---|
| `argocd.<domain>` | hub IP `127.0.0.10` | `argocd.kindell247` |
| `<app>.<env>.<domain>` | that environment's IP | `python.dev.kindell247` → `127.0.0.11` |
| anything else | your normal DNS | `github.com` → your Wi-Fi's resolver |

`<domain>` is `lab_domain` in `lab.yml`.

- **`lab-dns.service`** is a dedicated dnsmasq with its own config
  (`/etc/lab-dns/dnsmasq.conf`). It answers **only** the lab domain and never
  forwards, so it can't leak or intercept other lookups. Any other dnsmasq on
  the machine is untouched.
- **`/etc/systemd/resolved.conf.d/60-lab-dns.conf`** sets `Domains=~<domain>`,
  so resolved sends only lab names there.
- Records are wildcards: any name under `dev.<domain>` resolves to dev's IP.
  All environments get records, even disabled ones, so the config stays stable.

Check it with `resolvectl query python.dev.kindell247`.

- **ECDSA P-384** root, valid 10 years (`lab_ca_valid_days`).
- **Name-constrained** to the lab domain (critical extension). Even though your
  machine trusts it, it **cannot** be used to issue a valid certificate for any
  other site.
- `pathlen:0`, so it can't create intermediate CAs.
- The key is copied into each cluster as `cert-manager/lab-ca` by Ansible. It
  is **never** in Git.

## Certificate issuance

- Workers get a **wildcard** `*.<env>.<domain>`.
- The hub gets an exact `argocd.<domain>`. Browsers treat an unknown top-level
  name like `kindell247` as a public suffix, so a bare `*.kindell247` wildcard
  would be rejected.

## Browsers

| Browser | Trusted? | Notes |
|---|---|---|
| curl, Python, Go tools | ✔ | Use the OS trust store |
| Chromium / Chrome | ✔ | NSS db `~/.pki/nssdb`. Restart the browser once after the CA is added. |
| Firefox | ✘ by default | Own store per profile. Add the profile path to `lab_ca_nss_dbs` in `lab.yml`. |

> [!tip] Typing addresses
> Type the full `https://python.dev.kindell247` the first time. Browsers don't
> know the `.kindell247` ending and may run a search instead.

## Changing the domain

Change `lab_domain` in `lab.yml`, then `make redeploy`. DNS records, the
resolved routing domain, a new CA, certificates, hostnames and smoke tests all
follow. Nothing in either repo mentions the old name.
