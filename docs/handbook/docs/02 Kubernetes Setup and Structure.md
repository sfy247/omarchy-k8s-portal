## Topology: hub and spoke

Every cluster is a single-node **kind** cluster, running Kubernetes v1.37 as a
Docker container. The **hub** (`mgmt`) runs the only Argo CD. **Worker**
clusters, one per environment, run the apps. You see everything in one Argo CD UI.

## What runs in each cluster

| Namespace | Hub (`mgmt`) | Workers | Contents |
|---|---|---|---|
| `argocd` | ✔ | | Argo CD (server, repo-server, application + ApplicationSet controllers, redis) |
| `cert-manager` | ✔ | ✔ | cert-manager + the `lab-ca` secret (written by Ansible) |
| `envoy-gateway-system` | ✔ | ✔ | Envoy Gateway controller + the Envoy proxy for the shared gateway |
| `gateway` | ✔ | ✔ | The `shared` Gateway, its TLS certificate, the HTTP→HTTPS redirect |
| `hello-world` | | ✔ | The four apps (Pod Security `restricted`) |
| `kube-system` | ✔ | ✔ | CoreDNS, kindnet (CNI), kube-proxy, control plane; `argocd-manager` SA on workers |
| `local-path-storage` | ✔ | ✔ | kind's default storage provisioner |

## Platform repo structure

`omarchy-k8s-platform` holds everything that runs in a cluster. Folders name
their **content**, not the tool that applies them.

```
omarchy-k8s-platform/
├── bootstrap/                     ← root app of apps syncs this (on the hub)
│   ├── projects.yaml              AppProjects: platform, default (emptied)
│   ├── environments.yaml          ApplicationSet: env-<name> per registered worker
│   └── cluster-addons.yaml        AppProject + ApplicationSets for add-ons (versions pinned here)
├── cluster-addons/
│   └── gateway/                   Helm chart: GatewayClass, Gateway, cert, redirect, Argo CD route
├── environments/
│   ├── dev/hello-world/           project.yaml + appset.yaml → dev cluster
│   ├── staging/hello-world/       → staging cluster
│   └── prod/hello-world/          → prod cluster
├── apps/
│   └── hello-world/
│       ├── python/                src/, Dockerfile, values.yaml, values-prod.yaml
│       ├── dotnet/   node/   java/
└── charts/
    └── web-service/               the hardened chart every app uses
```

## The apps

| App | Language / runtime | Base image | Port | Dev NodePort |
|---|---|---|---|---|
| python | Python 3.13 stdlib `http.server` | `python:3.13-slim` | 8080 | 30001 |
| dotnet | C# / .NET 10 minimal API | `aspnet:10.0-noble-chiseled` (no shell) | 8080 | 30002 |
| node | Node 24 `http` | `node:24-alpine` | 8080 | 30003 |
| java | Java 25 `HttpServer`, virtual threads | `eclipse-temurin:25-jre` | 8080 | 30004 |

Each serves `GET /` → `{"message": "Hello, World!", ...}` and `GET /healthz`
(used by the readiness and liveness probes). Images are built by Ansible and
side-loaded into each worker; they are never pushed to a registry.
